# Description 
A full-stack Retrieval-Augmented Generation (RAG) chat application built with Next.js. Upload your documents and chat with them intelligently using OpenAI embeddings, Pinecone vector search, and a clean authenticated UI.

# Features 
- Authentication — Secure sign-up/sign-in with Clerk 
- Document Uploads — Support for PDFs uploads 
- AI Embeddings — Documents are chunked and embedded using OpenAI's embedding models
- Vector Search — Semantic similarity search powered by Pinecone
- Streaming Chat — Streams real-time AI responses 
- Per-User Namespacing — Each user's documents are isolated in their own Pinecone namespace
